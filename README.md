# English to Jungle Language Converter

This is a practice project that demonstrates a static webpage converting English text to Jungle Language and vice versa. It's an introductory project created after completing a tutorial, exploring HTML, CSS, and JavaScript while getting familiar with Git and GitHub.

You can view the live demo of the project [here](https://rave-codes-67.github.io/jungle-language-converter/).

## Features

- Convert English text to Jungle Language and back.
- Simple and user-friendly interface.
- Built with plain HTML, CSS, and JavaScript.
- Responsive design for various screen sizes.

## Technologies Used

- **HTML**: For structuring the webpage.
- **CSS**: For styling the webpage.
- **JavaScript**: For functionality to convert text between languages.

## Getting Started

To get a local copy up and running, follow these steps:

1. Clone the repo:
   ```bash
   git clone https://github.com/Rave-codes-67/jungle-language-converter
   ```
2. Navigate to the project directory:
   ```bash
   cd jungle-language-converter
   ```
3. Open `index.html` in your web browser.

## Usage

1. Enter text in English in the input field.
2. Click on the "Convert to Jungle Language" button to translate.
3. To convert back, paste the Jungle Language text and click "Convert to English."
