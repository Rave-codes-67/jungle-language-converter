What is Jungle Language?

Jungle language is a private unofficial coded language used infrequently around the world; it allows people(friends, family, etc.) to chat and communicate in an interractive way both online and physically privately.

Its a simple made up language for secret communication, typically by combining vowels with numbers, and is not a real language like Inga or historical code.

How does jungle language work?

Like i mentioned above, Jungle language is not an official language so there are different methods of convertion, but the most common method is by replacing all vowels in a sentence with numbers, and thats the method i use and will be explained below.
ps. The converter also uses this method.

This method requires you to convert all the vowels[a, e, i, o, u] in your sentence to numbers[1, 2, 3, 4, 5] respectively, therefore: a = 1, e = 2, i = 3, o = 4, u = 5. And then add 'a' to the back of the consonants.


examples:
1. how are you doing -> ha4wa 1ra2 ya45 da43naga.
2. Jungle Language is actually easy -> Ja5nagala2 La1naga51ga2 3sa 1cata51lalaya 21saya.
3. Practice with the converter -> Para1cata3ca2 wa3taha taha2 ca4nava2rata2ra
4. It's not that hard -> Iata'sa na4ta taha1ta ha1rada
